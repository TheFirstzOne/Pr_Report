# Job Diary Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "บันทึกประจำวัน" (job diary) tab to the dashboard: a shared team log backed by a Google Doc, ported from the standalone `JobdiaryRecord/job_diary_app.py` Flet app.

**Architecture:** Read is client-side only — direct `fetch` of the Doc's public `export?format=txt` URL, parsed in JS (no Apps Script round-trip, matching every other read in this app). Write is one new `Code.gs` `doPost` action using `DocumentApp` (not `SpreadsheetApp` — the first write action in this file that doesn't touch the spreadsheet). No optimistic local state — after a successful write, the client just re-fetches the Doc, since there's no in-memory diary array to reconcile against.

**Tech Stack:** Vanilla JS, Tailwind CDN (existing), `DocumentApp` (Apps Script built-in, no new dependency).

## Global Constraints

- Diary Doc ID: `1DuuoQhKA9WNgndt2q1V8Am2tiq0epy5AKBeHtHWU9yA` — already created, shared "Anyone with the link – Viewer", verified reachable at `https://docs.google.com/document/d/1DuuoQhKA9WNgndt2q1V8Am2tiq0epy5AKBeHtHWU9yA/export?format=txt` (confirmed `200 OK` before this plan was written).
- Entry format (paragraphs in the Doc, one entry per date+time, `=`×80 divider between entries — extends the original app's format with one added line): `📅 วันที่: DD/MM/YYYY HH:MM:SS` / `โดย: {ชื่อ}` / `{เนื้อหา}`.
- Date grouping must sort by an actually-parsed `Date`, never by the raw `DD/MM/YYYY` string (the original app's plain string sort mis-orders across month/year boundaries — this is a correctness fix over the original app, not a preference).
- `who` is always the currently logged-in user (`localStorage.maintxProCurrentUser`, same read pattern `submitFeedback()` already uses — `"ไม่ระบุตัวตน"` fallback), never a free-typed field.
- The 2 pre-existing entries from `job_diary.docx` have no author — the parser must tolerate a missing `โดย:` line (display `"ไม่ระบุ"`), not require it.
- `Code.gs` write handlers in this file use `LockService` only when there's a read-modify-write race on a specific row/range to guard against (`CLAUDE.md`'s convention, and `submitFeedback_`'s own comment explaining why it skips the lock) — `addDiaryEntry_` is append-only, same reasoning applies, no lock.
- No test framework in this project — every task ends with a manual browser/console verification.
- Thai UI copy only, matching the existing tabs' tone.
- Spec: `docs/superpowers/specs/2026-08-06-job-diary-design.md`.

```javascript
        // Ported from JobdiaryRecord/job_diary_app.py's parse_diary_entries.
        // Splits the diary Doc's plain-text export into per-date entry
        // groups. Content lines run until the next 📅 date line or end of
        // text; blank lines and the "===...=" divider between entries are
        // dropped, not treated as content.
        function parseDiaryText_(text) {
            const lines = text.replace(/\r\n/g, "\n").split("\n");
            const dateRe = /^📅 วันที่: (\d{2})\/(\d{2})\/(\d{4}) (\d{2}:\d{2}:\d{2})$/;
            const whoRe = /^โดย: (.*)$/;
            const dividerRe = /^=+$/;

            const entriesByDate = {};
            let currentDateKey = null;
            let currentTime = null;
            let currentWho = "";
            let currentContentLines = [];
            let sawFirstLineAfterDate = false;

            function flush() {
                if (currentDateKey && currentContentLines.length > 0) {
                    if (!entriesByDate[currentDateKey]) entriesByDate[currentDateKey] = [];
                    entriesByDate[currentDateKey].push({
                        time: currentTime,
                        who: currentWho || "ไม่ระบุ",
                        content: currentContentLines.join("\n")
                    });
                }
            }

            lines.forEach(function (raw) {
                const line = raw.trim();
                const dateMatch = dateRe.exec(line);
                if (dateMatch) {
                    flush();
                    currentDateKey = dateMatch[1] + "/" + dateMatch[2] + "/" + dateMatch[3];
                    currentTime = dateMatch[4];
                    currentWho = "";
                    currentContentLines = [];
                    sawFirstLineAfterDate = false;
                    return;
                }
                if (!currentDateKey) return;

                // "โดย:" only ever appears as the line immediately after a
                // date line (per addDiaryEntry_'s write order) — checked
                // once per entry, never again once that slot is consumed,
                // so a legitimate content line that happens to start with
                // "โดย:" later in the same entry isn't misread as the author.
                if (!sawFirstLineAfterDate) {
                    sawFirstLineAfterDate = true;
                    const whoMatch = whoRe.exec(line);
                    if (whoMatch) {
                        currentWho = whoMatch[1].trim();
                        return;
                    }
                }

                if (line === "" || dividerRe.test(line)) return;
                currentContentLines.push(line);
            });
            flush();

            const dateKeys = Object.keys(entriesByDate).sort(function (a, b) {
                return parseDDMMYYYY_(b) - parseDDMMYYYY_(a);
            });

            return dateKeys.map(function (dateKey) {
                return { date: dateKey, entries: entriesByDate[dateKey] };
            });
        }

        // Sorts by an actual calendar date, not the DD/MM/YYYY string — the
        // original desktop app's plain string sort mis-orders across
        // month/year boundaries (e.g. "05/02/2026" < "13/01/2026" lexically
        // despite being chronologically later).
        function parseDDMMYYYY_(dateKey) {
            const parts = dateKey.split("/");
            return new Date(Number(parts[2]), Number(parts[1]) - 1, Number(parts[0])).getTime();
        }

        // Diary content is free-typed, often-multiline text — the one new
        // interpolation site in this feature most likely to carry characters
        // that would otherwise be read as HTML, so it's escaped explicitly
        // here rather than interpolated raw.
        function escapeDiaryHtml_(text) {
            const div = document.createElement("div");
            div.textContent = text;
            return div.innerHTML;
        }
```

```javascript
        function fetchDiaryEntries() {
            const loading = document.getElementById("diary-list-loading");
            const empty = document.getElementById("diary-list-empty");
            const errorBox = document.getElementById("diary-list-error");
            const wrapper = document.getElementById("diary-list-wrapper");

            empty.classList.add("hidden");
            errorBox.classList.add("hidden");

            fetch("https://docs.google.com/document/d/1DuuoQhKA9WNgndt2q1V8Am2tiq0epy5AKBeHtHWU9yA/export?format=txt")
                .then(function (res) { return res.text(); })
                .then(function (text) {
                    loading.classList.add("hidden");
                    diaryEntriesByDate = parseDiaryText_(text);
                    if (diaryEntriesByDate.length === 0) {
                        empty.classList.remove("hidden");
                        return;
                    }
                    wrapper.classList.remove("hidden");
                    selectedDiaryDate = diaryEntriesByDate[0].date;
                    renderDiaryDateList_();
                    renderDiaryEntriesForSelectedDate_();
                })
                .catch(function (err) {
                    console.error(err);
                    loading.classList.add("hidden");
                    errorBox.classList.remove("hidden");
                });
        }

        function renderDiaryDateList_() {
            const container = document.getElementById("diary-date-list");
            container.innerHTML = diaryEntriesByDate.map(function (group) {
                const isActive = group.date === selectedDiaryDate;
                const activeClass = isActive ? "bg-indigo-50 text-indigo-700 font-bold" : "text-slate-600 hover:bg-slate-50";
                return `
                    <button type="button" onclick="selectDiaryDate('${group.date}')" class="w-full text-left px-3 py-2.5 text-xs ${activeClass} transition-colors">
                        ${group.date}
                    </button>
                `;
            }).join("");
        }

        function selectDiaryDate(date) {
            selectedDiaryDate = date;
            renderDiaryDateList_();
            renderDiaryEntriesForSelectedDate_();
        }

        function renderDiaryEntriesForSelectedDate_() {
            const container = document.getElementById("diary-entries-body");
            const group = diaryEntriesByDate.find(function (g) { return g.date === selectedDiaryDate; });

                            <span class="text-xs text-slate-400">${entry.who}</span>
                        </div>
                        <p class="text-sm text-slate-700 whitespace-pre-line">${escapeDiaryHtml_(entry.content)}</p>
                    </div>
                `;
            }).join("");
        }
```

```javascript
        function submitDiaryEntry(event) {
            event.preventDefault();
            if (inFlightDiary) return;

            const contentField = document.getElementById("form-diary-content");
            const content = contentField.value.trim();
            if (!content) return;

            const userRaw = localStorage.getItem("maintxProCurrentUser");
            const user = userRaw ? JSON.parse(userRaw) : null;
            const who = user && user.name ? user.name : "ไม่ระบุตัวตน";

            inFlightDiary = true;
            const btn = document.getElementById("diary-submit-btn");
            btn.setAttribute("disabled", "true");
            btn.innerText = "กำลังบันทึก...";

            fetch(EXEC_URL, {
                method: "POST",
                body: JSON.stringify({
                    action: "addDiaryEntry",
                    who: who,
                    content: content
                })
            })
            .then(function (res) { return res.json(); })
            .then(function (data) {
                if (data.error) {
                    throw new Error(data.error);
                }
                contentField.value = "";
                triggerToast("บันทึกสำเร็จ", "success");
                fetchDiaryEntries();
            })
            .catch(function (err) {
                console.error(err);
                triggerToast("บันทึกไม่สำเร็จ กรุณาลองใหม่", "error");
            })
            .finally(function () {
                inFlightDiary = false;
                btn.removeAttribute("disabled");
                btn.innerText = "บันทึก";
            });
        }

```
